# 08 — Windows Log Collection

## SIEM Engineer Interview Questions

### Topic 01: Windows Event Log Architecture & Subsystems

1. How does the Windows Event Log (EVTX) architecture operate in modern Windows operating systems, and what are the structural differences between classic channels (Security, System, Application) and Applications and Services channels (`Microsoft-Windows-*`)?
2. How are Windows Event Logs stored in binary XML format, and how does dynamic field extraction (System metadata vs. EventData payload) function when an endpoint agent reads these logs?
3. How should Event Viewer channel buffer sizes (Maximum Log Size) and retention policies ("Overwrite events as needed" vs. "Archive the log when full") be configured to ensure critical security events are never overwritten or permanently lost?
4. How much event log volume (in MB or GB per day) is typically generated by a standard Windows workstation compared to an Active Directory Domain Controller, and how do you accurately measure and calculate this baseline?
5. What is the operational and security impact if the Windows Event Log service (`eventlog`) crashes or is manually stopped, and how can a SIEM immediately detect this evasion condition?

### Topic 02: Advanced Security Audit Policy Configuration

6. Why is default basic auditing in Windows completely inadequate for enterprise security, and why must Advanced Audit Policy Configuration be strictly enforced via Group Policy Objects (GPO)?
7. What are the recommended baseline configurations for Success and Failure auditing across Account Logon (Events 4624, 4625), Account Management (Events 4720, 4724, 4738), and Privilege Use (Events 4672, 4673)?
8. What is the security significance of enabling "Audit Process Creation" along with command-line argument tracking ("Include command line in process creation events" - Event ID 4688), and how is it implemented?
9. How do you configure System Access Control Lists (SACLs) in conjunction with the "Audit Object Access" policy to track read, write, and delete operations on sensitive file shares?
10. How do you prevent Domain Controller performance degradation or log flooding caused by overly verbose audit policies (e.g., thousands of successful Filtering Platform connection events like Event ID 5156/5158 per second)?

### Topic 03: Sysmon Architecture & Modular Configuration

11. What is Microsoft Sysinternals Sysmon, and at what architectural level (kernel-mode device minifilter driver vs. user-mode service) does it operate?
12. Why is Sysmon Event ID 1 (Process Creation with file hashes, ParentProcessId, and full CommandLine) considered a game-changer for detection engineers despite the existence of standard Windows Security Event ID 4688?
13. Explain the detection significance of key Sysmon event IDs: Network Connection (Event ID 3), Driver Loaded (Event ID 6), Image Loaded (Event ID 7), Process Access / LSASS injection (Event ID 10), and File Creation (Event ID 11).
14. What are the advantages of adopting community-tested modular Sysmon configurations (e.g., SwiftOnSecurity or Olaf Hartong's Sysmon-Modular) in production, and how do you filter out high-volume benign noise such as browser network connections?
15. How do you leverage Sysmon Event ID 22 (DNS Query) on Domain Controllers or client endpoints to track DNS tunneling and malicious domain resolution, and how do you manage the resulting log volume overhead?

### Topic 04: PowerShell Auditing, Script Block & Transcription

16. Which three core PowerShell auditing policies (Module Logging, Script Block Logging, and Transcription) must be configured to detect fileless malware and memory-resident attacks?
17. How does PowerShell Script Block Logging (Event ID 4104) capture de-obfuscated and unpacked script code dynamically in memory even when attackers employ layers of Base64 encoding or string obfuscation?
18. How do you securely centralize, restrict file permissions on, and ingest PowerShell Transcription output log files into a SIEM using an endpoint agent?
19. How do you detect or completely disable/remove legacy PowerShell Version 2.0 (often utilized by adversaries to bypass modern Script Block Logging) across enterprise endpoints?
20. How do the logging channels and configuration mechanisms for PowerShell 7 (PowerShell Core) differ from traditional Windows PowerShell 5.1 on Windows and Linux hosts?

### Topic 05: Active Directory & Domain Controller Log Collection

21. Why is it critical to collect and monitor Kerberos Authentication Service requests (Event ID 4768), Service Ticket requests (Event ID 4769), and Pre-Authentication failures (Event ID 4771) from Active Directory Domain Controllers?
22. How do you capture privileged group membership modifications (e.g., additions to Domain Admins or Enterprise Admins via Event IDs 4728 and 4732) and Group Policy Object (GPO) modifications (Event IDs 5136 and 5137) in real time?
23. Which Directory Service access and replication events must be monitored to detect Active Directory database (`NTDS.dit`) exfiltration, Volume Shadow Copy abuse, and DCSync attacks?
24. How do you configure targeted event channel filtering on Domain Controllers to collect only security-critical events while minimizing agent CPU and memory consumption under high load?
25. What is the role of Active Directory Domain Controller clock synchronization (NTP) in detecting Kerberos Golden/Silver Ticket attacks and cross-domain trust manipulations?

### Topic 06: Event Channel Filtering, XPath Queries & Noise Suppression

26. How do you construct and utilize XPath queries (`<QueryList>`) within endpoint agent configurations to suppress benign noise and reduce SIEM ingestion and license costs?
27. Provide an example of an XPath filter expression that strictly collects Event IDs 4624, 4625, 4688, 4720, and 4728 from the Security log channel while dropping all other events at the source.
28. How do you filter out routine, high-volume logon events generated by local system service accounts (such as `NT AUTHORITY\SYSTEM` or `LOCAL SERVICE`) to ensure user-driven authentication activity remains clear?
29. What methodology and metrics should be implemented to periodically audit and validate that source-level log filtering is not dropping genuine security-relevant events?
30. How do you architect and deploy tiered Windows logging profiles (e.g., Minimal Baseline for general workstations vs. High-Fidelity Forensic Profile for critical servers and executive endpoints)?

### Topic 07: Windows Event Forwarding (WEF) & Collector (WEC) Architecture

31. How do you design an agentless, centralized log collection architecture utilizing native Windows Event Forwarding (WEF) and Windows Event Collector (WEC)?
32. How do you configure source-initiated (push) versus collector-initiated (pull) subscriptions in an Active Directory environment using WinRM, Kerberos authentication, and Group Policy?
33. What is the recommended and reliable architectural mechanism to forward aggregated event logs from centralized WEC servers to the SIEM processing pipeline?
34. What are the architectural challenges and implementation steps for configuring WEC subscriptions over HTTPS using mutual certificate-based authentication for workgroup or non-domain-joined machines?
35. How do you evaluate the advantages (native OS support, agentless, Kerberos encryption) versus operational limitations (single point of failure risk, lack of endpoint active response) of a WEF/WEC architecture?

### Topic 08: Specialized Windows Logs: Defender, Firewall & DNS

36. What event channels and configurations are required to capture Microsoft Defender Antivirus / Defender for Endpoint detection events (Event ID 1116 - Threat Detected, 1117 - Action Taken) and unauthorized exclusion list modifications?
37. How do you capture and ingest Windows Filtering Platform (WFP / Windows Advanced Firewall) blocked network connection events (Event ID 5157) without degrading host CPU performance or overwhelming network bandwidth?
38. How do you configure an endpoint agent to collect and parse flat-file Windows DHCP Audit Logs (`%SystemRoot%\System32\dhcp\DhcpSrvLog-*.log`) for dynamic IP-to-MAC address lease tracking?
39. How do you ingest DNS query and response logs from enterprise Windows DNS servers using the ETW-based DNS Server Analytical channel or debug logging without degrading DNS resolution performance?
40. How do you configure real-time collection, field parsing, and streaming of W3C format access logs from Microsoft Internet Information Services (IIS) web servers to a SIEM?

### Topic 09: Log Ingestion Integrity, Dropped Events & Anti-Forensics

41. How do you ensure high-priority alerting and immediate SIEM ingestion when an attacker attempts anti-forensics by clearing the Windows Security log (Event ID 1102 - "The audit log was cleared")?
42. How do you guarantee near-real-time agent log shipping and appropriate circular logging policies to prevent buffer exhaustion and Event ID 1104 ("The security log is now full")?
43. How can a SIEM detect advanced anti-forensic evasion techniques designed to suspend or tamper with event logging (e.g., registry modifications, terminating eventlog service worker threads via tools like Phant0m)?
44. How do you monitor and alert on time delta discrepancies between the event generation timestamp (`TimeCreated SystemTime`) and the SIEM ingestion timestamp (`IngestionTime`) caused by agent backlog or network latency?
45. How do endpoint log shippers utilize persistent disk queues and bookmarking/checkpointing to preserve uncommitted events during network outages or unexpected host reboots?

### Topic 10: End-to-End Validation, Attack Simulation & Testing

46. How do you conduct controlled attack simulation tests using frameworks like Atomic Red Team or custom scripts to validate end-to-end Windows log ingestion pipelines?
47. How do you verify that credential dumping activity (e.g., executing Mimikatz against LSASS memory) on a test endpoint is properly captured in Sysmon Event ID 10 and Security Event IDs 4656/4663?
48. What is the verification procedure for simulating a Kerberoasting attack and confirming that Event ID 4769 (with RC4 ticket encryption type `0x17`) is generated on the Domain Controller and indexed in the SIEM?
49. How do you query raw Windows events in the SIEM search interface to validate that critical normalized fields—such as Username, Domain, Source IP, Process Name, and CommandLine—are accurately extracted?
50. How do you generate, validate, and present a comprehensive "Windows Logging Compliance & Audit Baseline Report" covering 500+ enterprise Windows systems to a CISO or compliance auditor?
