# 05 — Linux Server Deployment

## SIEM Engineer Interview Questions

### Topic 01: Linux Distribution Selection & Base OS Architecture

1. প্রোডাকশন এন্টারপ্রাইজ SIEM (যেমন: Wazuh, Elastic, Splunk)-এর জন্য RHEL/Rocky Linux এবং Ubuntu Server LTS-এর মধ্যে নির্বাচন করার ক্ষেত্রে কোন টেকনিক্যাল বিষয়গুলো (কার্নেল স্ট্যাবিলিটি, লং-টার্ম সাপোর্ট, প্যাকেজ ম্যানেজমেন্ট, ভেন্ডর সার্টিফিকেশন) বিবেচনা করবে?
2. একটি SIEM সার্ভারে কেন সবসময় "Minimal Install" ব্যবহার করা উচিত এবং অপ্রয়োজনীয় প্যাকেজ বা GUI সার্ভিস অপসারণ না করলে কী ধরনের সিকিউরিটি অ্যাটাক সারফেস ও পারফরম্যান্স পেনাল্টি তৈরি হয়?
3. CIS (Center for Internet Security) Linux Benchmark অথবা DISA-STIG স্ট্যান্ডার্ড অনুযায়ী প্রোডাকশন SIEM সার্ভারের বেস ওএস হার্ডেনিং করার জন্য কোন চেকলিস্ট অনুসরণ করবে?
4. সার্ভার প্রভিশনিংয়ের সময় কার্নেল ভার্সন (Kernel version) এবং এর আর্কিটেকচারাল কম্প্যাটিবিলিটি (যেমন: eBPF সাপোর্ট, আধুনিক NVMe ড্রাইভার, লেটেস্ট নেটওয়ার্কিং প্রটোকল) কীভাবে যাচাই করবে?
5. ক্লাউড ভার্চুয়াল মেশিন (AWS EC2, Azure VM), অন-প্রিম VMware ESXi/Proxmox এবং বেয়ার-মেটাল (Bare-metal) ফিজিক্যাল সার্ভারের ক্ষেত্রে লিনাক্স ওএস ইনস্টলেশনের কী কী মৌলিক পার্থক্য তৈরি হয়?

### Topic 02: Storage, Filesystem Architecture & Partitioning

6. একটি SIEM সার্ভারের জন্য লজিক্যাল ভলিউম ম্যানেজার (LVM) ব্যবহার করে `/var/log`, `/var/ossec` (বা ডাটা ডিরেক্টরি), `/tmp`, এবং `/home`-এর পার্টিশনিং স্কিম কীভাবে ডিজাইন করবে?
7. ডেটাবেজ বা ইনডেক্সার স্টোরেজ পার্টিশন পূর্ণ হয়ে গেলেও অপারেটিং সিস্টেম যাতে ক্র্যাশ না করে, সেজন্য রুট ফাইলসিস্টেম (`/`) থেকে ইনজেশন ও লগ ডিরেক্টরি সম্পূর্ণ আলাদা মাউন্ট পয়েন্টে রাখা কেন বাধ্যতামূলক?
8. হাই-থ্রুপুট SIEM ইনডেক্সিং এবং ক্রমাগত ডেটা রাইটের জন্য XFS এবং ext4 ফাইলসিস্টেমের মধ্যে কোনটি বেশি উপযোগী এবং কেন?
9. মাউন্ট অপশনে `noatime`, `nodiratime`, `barrier=0` (বা write-back cache) এবং `discard` কনফিগার করলে ডিস্ক I/O পারফরম্যান্সে কী প্রভাব ফেলে এবং ডেটা ইন্টিগ্রিটির কী রিস্ক তৈরি হতে পারে?
10. LVM-এ রানটাইমে কোনো ডাউনটাইম ছাড়াই প্রোডাকশন ডেটা ভলিউম অনলাইন এক্সপ্যান্ড (Live Volume Extension & Filesystem Resize) করার নিরাপদ পদ্ধতি কী?

### Topic 03: Linux Kernel Performance Tuning & Sysctl Optimization

11. Elasticsearch বা OpenSearch-ভিত্তিক SIEM ইনডেক্সার চালু করার পূর্বে কার্নেলের `vm.max_map_count` ডিফল্ট (৬৫৫৩০) থেকে বাড়িয়ে কেন কমপক্ষে ২৬২১৪৪ (বা তদূর্ধ্ব) করতে হয় এবং এর অন্তর্নিহিত মেমোরি ম্যাপিং মেকানিজম কী?
12. লিনাক্স কার্নেলের `vm.swappiness` প্যারামিটারটিকে কেন ১ (বা ০)-তে নামিয়ে আনা হয় এবং প্রোডাকশনে সোয়াপ মেমোরি ব্যবহার করলে জাভা গারবেজ কালেকশন (GC) পজে কীভাবে মারাত্মক বিপর্যয় ঘটে?
13. হাই-ভলিউম ডেটা রাইটের সময় কার্নেলের ডার্টি মেমোরি ফ্ল্যাশিং কন্ট্রোল করতে `vm.dirty_background_ratio` এবং `vm.dirty_ratio` কীভাবে টিউন করবে যাতে সিস্টেম I/O স্টল (Stall) না হয়?
14. সম্পূর্ণ সিস্টেমের গ্লোবাল ফাইল ডিসক্রিপ্টর সীমা বাড়াতে `fs.file-max` কনফিগারেশনের ভূমিকা কী এবং এটি কীভাবে হিসাব করা হয়?
15. রিবুট করার পরেও এই কার্নেল সেটিংস যেন পারসিস্টেন্ট থাকে, সেজন্য `/etc/sysctl.d/` ডিরেক্টরিতে কনফিগারেশন ম্যানেজমেন্টের বেস্ট প্র্যাকটিস কী?

### Topic 04: Process Limits, Systemd & Resource Management

16. `/etc/security/limits.conf` ফাইলে SIEM প্রসেস সার্ভিস ইউজারদের জন্য `nofile` (Number of Open Files: যেমন ৬৫৫৩৬ বা তদূর্ধ্ব) এবং `nproc` (Number of Processes) টিউন করা কেন অপরিহার্য?
17. সিস্টেমড (Systemd) সার্ভিসে অনেক সময় `limits.conf`-এর মান ওভাররাইড হয়ে ডিফল্ট লিমিট চলে আসে—সার্ভিস ইউনিট ফাইলে `LimitNOFILE=65536` এবং `LimitNPROC=4096` কীভাবে প্রপারলি কনফিগার করবে?
18. মেমোরি পেজ সোয়াপিং বন্ধ রাখতে `LimitMEMLOCK=infinity` এবং কনফিগারেশনে `bootstrap.memory_lock: true` দেওয়ার উদ্দেশ্য কী এবং এটি কার্যকর হয়েছে কিনা কীভাবে ভেরিফাই করবে?
19. Systemd Cgroups (Control Groups) ব্যবহার করে একটি মিসবিহেভিং কাস্টম স্ক্রিপ্ট বা পার্সার যাতে পুরো সার্ভারের ১০০% CPU বা RAM দখল করে সিস্টেম ক্র্যাশ না করায়, সেজন্য রিসোর্স কোটা (`CPUQuota`, `MemoryLimit`) কীভাবে সেট করবে?
20. `systemd-system.conf` এবং `/etc/systemd/system/` ওভাররাইড ড্রপ-ইন ফাইলের (`override.conf`) মধ্যে স্ট্যান্ডার্ড আর্কিটেকচারাল প্র্যাকটিস কোনটি?

### Topic 05: Network Stack Tuning & High-Throughput Socket Optimization

21. সেকেন্ডে হাজার হাজার সিসলগ (Syslog UDP/TCP) প্যাকেট হ্যান্ডেল করার জন্য লিনাক্স সকেট রিসিভ বাফার (`net.core.rmem_max`, `net.core.rmem_default`) এবং সেন্ড বাফার কীভাবে অপ্টিমাইজ করবে?
22. হঠাৎ আসা ট্রাফিকের কারণে সকেট ড্রপ রোধ করতে কার্নেল নেটওয়ার্ক কিউ `net.core.netdev_max_backlog` এবং ইনকামিং কানেকশন ব্যাকলগ `net.core.somaxconn` কেন ডিফল্ট ১২৮ থেকে বাড়িয়ে ১০২৪ বা ৪০৯৬ করতে হয়?
23. TCP কানেকশন দ্রুত রিলিজ ও টাইম-ওয়েট স্টেট কমাতে `net.ipv4.tcp_tw_reuse`, `net.ipv4.tcp_fin_timeout` এবং TCP কিপ-অ্যালাইভ (`tcp_keepalive_time`, `tcp_keepalive_probes`) কীভাবে কনফিগার করবে?
24. নেটওয়ার্ক ইন্টারফেস কার্ডে (NIC) প্যাকেট ড্রপ বন্ধ করতে `ethtool` দিয়ে Ring Buffer (RX/TX ring parameters) সর্বোচ্চ ক্যাপাসিটিতে কীভাবে বাড়াবে?
25. লার্জ স্কেল ইনজেশনের জন্য জাম্বো ফ্রেম (Jumbo Frames: MTU 9000) ব্যবহারের প্রয়োজনীয়তা কখন দেখা দেয় এবং এন্ড-টু-এন্ড সুইচ ও রাউটারের সাথে এর সামঞ্জস্য কীভাবে পরীক্ষা করবে?

### Topic 06: Time Synchronization, PTP & Chrony Engineering

26. একটি SIEM এনভায়রনমেন্টে মাইক্রোসেকেন্ড বা মিলি-সেকেন্ড লেভেলের টাইম সিনক্রোনাইজেশন কেন জীবন-মরণ সমস্যা এবং টাইম ডিফারেন্সের কারণে কোরিলেশন রুল কীভাবে ব্যর্থ হয়?
27. আধুনিক লিনাক্সে `ntpd`-এর তুলনায় `chrony` কেন বহুগুণ দ্রুত এবং নির্ভরযোগ্যভাবে সার্ভার ক্লক সিঙ্ক করতে পারে?
28. এন্টারপ্রাইজ নেটওয়ার্কে একাধিক ইন্টারনাল Stratum 1 / Stratum 2 NTP সার্ভার পুল কনফিগার করে হাইলি ফল্ট-টলারেন্ট `/etc/chrony.conf` কীভাবে প্রস্তুত করবে?
29. কার্নেল সিস্টেম ক্লকে লিপ-সেকেন্ড (Leap Second) কীভাবে হ্যান্ডেল করা উচিত এবং ক্লাউড প্রোভাইডারদের "Leap Smearing" টেকনোলজির সাথে SIEM-এর আচরণ কেমন হওয়া উচিত?
30. `chronyc sources -v`, `chronyc tracking` এবং সিসলগ নিরীক্ষণ করে কীভাবে টাইম ড্র্রিফ্ট (Clock Drift) ও জিটার (Jitter) স্বয়ংক্রিয়ভাবে অ্যালার্ট করবে?

### Topic 07: Linux Firewalling, Network Security & Interface Isolation

31. প্রোডাকশন SIEM নোডে `firewalld` বা `nftables` ব্যবহার করে "Default Deny All" ইনবাউন্ড পলিসি কীভাবে বাস্তবায়ন করবে?
32. ম্যানেজমেন্ট ট্রাফিক (SSH, Web UI, API) এবং ইনজেশন ট্রাফিক (Syslog 514, Agent 1514, Logstash 5044) পৃথক ইন্টারফেসে ভাগ করে নির্দিষ্ট সোর্স আইপি বা সাবনেট দিয়ে সীমাবদ্ধ (IP Whitelisting) করার নিয়ম কী?
33. র-সিসলগ (UDP port 514) ড্রপ হওয়া থেকে রক্ষা করতে লিনাক্স কার্নেল ও ফায়ারওয়াল স্তরে কোনো বিশেষ কনফিগারেশন প্রয়োজন হয় কি না?
34. ফায়ারওয়ালে রেট-লিমিটিং (Rate Limiting / Connection Throttling) কনফিগার করে সিন-ফ্লাড (SYN Flood) বা আনঅথরাইজড পোর্ট স্ক্যান থেকে সার্ভারকে কীভাবে সুরক্ষিত রাখবে?
35. SIEM সার্ভার থেকে এক্সটার্নাল কোনো আউটবাউন্ড কানেকশন (egress) কেবল অনুমোদিত Threat Intel বা ভেন্ডর আপডেট রিপোজিটরি ছাড়া বাকি সব কীভাবে কঠোরভাবে ব্লক করবে?

### Topic 08: OS-Level Security, SELinux / AppArmor & Least Privilege

36. এন্টারপ্রাইজ লিনাক্সে SELinux কেন কখনোই `disabled` বা `permissive` করা উচিত নয় এবং প্রোডাকশন SIEM-কে কীভাবে `Enforcing` মোডে পরিচালনা করবে?
37. SIEM কম্পোনেন্টগুলো যদি নন-স্ট্যান্ডার্ড ডিরেক্টরিতে (যেমন: `/data/siem_logs` বা `/data/indexer`) লগ সংরক্ষণ করে, তবে সঠিক SELinux File Context (`semanage fcontext`, `restorecon`) কীভাবে প্রয়োগ করবে?
38. কাস্টম পোর্ট দিয়ে লগ রিসিভ বা API বাইন্ড করার ক্ষেত্রে SELinux Port Context (`semanage port -a -t ...`) কীভাবে এলাও করবে?
39. কোনো SIEM সার্ভিস (Wazuh, Logstash, Elasticsearch)-কে কেন কখনোই `root` ইউজার হিসেবে চালানো উচিত নয় এবং ডেডিকেটেড সার্ভিস একাউন্ট দিয়ে Least Privilege কীভাবে বজায় রাখবে?
40. `auditd` ব্যবহার করে সার্ভারের ক্রিটিক্যাল সিস্টেম ফাইল (`/etc/passwd`, `/etc/shadow`, `/etc/sysctl.conf`, `/etc/ssh/sshd_config`) এবং অ্যাডমিন কমান্ড এক্সিকিউশন ট্র্যাকিং কীভাবে নিশ্চিত করবে?

### Topic 09: Storage Performance Validation & Baseline Testing

41. সার্ভারে SIEM সফটওয়্যার ইনস্টল করার পূর্বে ড্রাইভের আসল Write IOPS, Read IOPS এবং Latency মাপার জন্য `fio` দিয়ে কীভাবে স্ট্যান্ডার্ড বেঞ্চমার্কিং স্ক্রিপ্ট চালাবে?
