# 07 — Endpoint Agent Deployment

## SIEM Engineer Interview Questions

### Topic 01: Agent Architecture, Capabilities & OS Support

1. একটি এন্টারপ্রাইজ SIEM এজেন্টের (যেমন: Wazuh Agent, Elastic Agent, Splunk Forwarder) অভ্যন্তরীণ আর্কিটেকচার কীভাবে কাজ করে এবং এটি ওএস কার্নেল নাকি ইউজার স্পেসে রান করে?
2. ভিন্ন ভিন্ন অপারেটিং সিস্টেম (Windows 10/11, Windows Server 2016-2022, RHEL, Ubuntu, Rocky Linux) সাপোর্টের ক্ষেত্রে এজেন্টের প্যাকেজ ভ্যারিয়ান্ট এবং ডিপেন্ডেন্সি কীভাবে ম্যানেজ করবে?
3. এজেন্ট-বেসড মনিটরিংয়ের ক্ষেত্রে লগ কালেকশন ছাড়াও ইন্টিগ্রিটি মনিটরিং (FIM), রুটকিট ডিটেকশন, ভালনারেবিলিটি স্ক্যানিং এবং সিকিউরিটি কনফিগারেশন অ্যাসেসমেন্ট (SCA)-এর মডিউলগুলো এজেন্টে কীভাবে কাজ করে?
4. সার্ভারের ক্রিটিক্যাল প্রোডাকশন অ্যাপ্লিকেশন যাতে এজেন্টের কোনো ত্রুটিতে ক্ষতিগ্রস্ত না হয়, সেজন্য এজেন্টের সার্ভিস আইসোলেশন ও এক্সিকিউশন প্রায়োরিটি কীভাবে নিশ্চিত করবে?
5. ক্লাউড ভার্চুয়াল মেশিন, ডকার কন্টেইনার এবং কুবেরনেটিস নোডে এজেন্ট ডিপ্লয়মেন্টের ক্ষেত্রে ট্র্যাডিশনাল ফিজিক্যাল সার্ভারের সাথে আর্কিটেকচারাল পার্থক্য কী?

### Topic 02: Automated Agent Deployment & Orchestration

6. একটি এন্টারপ্রাইজের ৫০০টি উইন্ডোজ এন্ডপয়েন্টে Active Directory Group Policy Object (GPO) অথবা Microsoft Intune/SCCM ব্যবহার করে নিরবচ্ছিন্নভাবে (Silent Installation) এজেন্ট কীভাবে ডিপ্লয় করবে?
7. লিনাক্স সার্ভার ফ্লিটগুলোতে (৫০+ সার্ভার) Ansible Playbook ব্যবহার করে কীভাবে একক কমান্ডে এজেন্ট ইনস্টলেশন, কনফিগারেশন পুশ এবং সার্ভিস অটো-এনেবল করবে?
8. গোল্ডেন ওএস ইমেজ বা টেমপ্লেট (VMware Template / AMI)-এ আগে থেকেই এজেন্ট প্রি-ইনস্টল করা থাকলে ক্লাস্টার বা সার্ভার ক্লোন করার পর ডুপ্লিকেট এজেন্ট আইডি সমস্যা কীভাবে সমাধান করবে?
9. ব্রাঞ্চ অফিসের রিমোট ল্যাপটপ বা ওয়ার্ক-ফ্রম-হোম ইউজার যারা ডোমেইনে সরাসরি কানেক্টেড নেই, তাদের জন্য এজেন্ট ডিস্ট্রিবিউশন ও অটো-এনরোলমেন্ট পাইপলাইন কীভাবে ডিজাইন করবে?
10. ডিপ্লয়মেন্ট অটোমেশন স্ক্রিপ্টে কোনো ফেইলিওর হলে (যেমন: নেটওয়ার্ক টাইমআউট বা কারাপ্ট প্যাকেজ) অটোমেটেড রিট্রাই ও এরর রিপোর্টিং কীভাবে কনফিগার করবে?

### Topic 03: Agent Enrollment, Registration & Key Management

11. নতুন একটি এন্ডপয়েন্ট যুক্ত হওয়ার সময় SIEM ম্যানেজারের সাথে এজেন্টের হ্যান্ডশেক ও অথেনটিকেশন (`agent-auth`, SSL/TLS সার্টিফিকেট, পাসওয়ার্ড ভ্যালিডেশন) প্রক্রিয়াটি টেকনিক্যালি কীভাবে সম্পন্ন হয়?
12. শত শত এন্ডপয়েন্ট একসাথে ডিপ্লয়মেন্টের জন্য স্বয়ংক্রিয় অটো-রেজিস্ট্রেশন (Auto-Enrollment using shared registration password বা enrollment token) কীভাবে কনফিগার করবে?
13. এজেন্টের ইউনিক এনক্রিপশন কি (`client.keys` ফাইল)-এর ভূমিকা কী এবং কেন প্রতিটি এজেন্টের জন্য একটি আলাদা সিমেট্রিক কি জেনারেট করা হয়?
14. ডাইনামিক আইপি (DHCP) ব্যবহার করা ল্যাপটপগুলোর ক্ষেত্রে আইপি পরিবর্তন হলেও যাতে এজেন্ট কমিউনিকেশন বা অথেনটিকেশন ব্রেক না করে, সেজন্য রেজিস্ট্রেশন পলিসিতে আইপি অ্যাসাইনমেন্ট কীভাবে কনফিগার করবে?
15. কোনো একটি এজেন্টের এনক্রিপশন কি বা ক্রেডেনশিয়াল কম্প্রোমাইজ হলে সেন্ট্রাল ম্যানেজার থেকে তাৎক্ষণিক সেই নির্দিষ্ট এজেন্টকে রিভোক ও ব্ল্যাকলিস্ট করার পদ্ধতি কী?

### Topic 04: Centralized Agent Configuration & Group Management

16. প্রতিটি এন্ডপয়েন্টে আলাদা আলাদা কনফিগারেশন ফাইল এডিট না করে সেন্ট্রাল ম্যানেজার থেকে `agent.conf` ব্যবহার করে সেন্ট্রালাইজড গ্রুপ কনফিগারেশন কীভাবে বাস্তবায়ন করবে?
17. ভিন্ন ভিন্ন ভূমিকার এন্ডপয়েন্টের জন্য (যেমন: `Windows-Workstations`, `Linux-WebServers`, `Domain-Controllers`, `DB-Servers`) আলাদা আলাদা গ্রুপ তৈরি করে স্পেসিফিক লগ কালেকশন পলিসি কীভাবে পুশ করবে?
18. একটি এন্ডপয়েন্ট যদি একই সাথে একাধিক গ্রুপের সদস্য হয় (Multi-group assignment), তবে কনফিগারেশন প্যারামিটারের মধ্যে কনফ্লিক্ট বা ওভাররাইড কীভাবে মীমাংসা হয়?
19. সেন্ট্রাল কনফিগারেশনে পরিবর্তন আনলে কোনো সার্ভিস ডাউনটাইম বা ইউজার ইন্টারাপশন ছাড়া এজেন্ট কীভাবে ডায়নামিকালি নতুন কনফিগারেশন পুল এবং অ্যাপ্লাই করে?
20. সেন্ট্রাল কনফিগারেশন পুশ করার পূর্বে এজেন্টের কনফিগারেশন পার্সিং ফেইলিওর হলে এজেন্ট যাতে ক্র্যাশ না করে লোকাল ব্যাকআপ কনফিগারেশনে রোলব্যাক করে, তা কীভাবে নিশ্চিত করবে?

### Topic 05: Resource Consumption & Host Protection

21. এজেন্ট যাতে কোনো অবস্থাতেই হোস্ট মেশিনের ১-২% এর বেশি CPU এবং ১০০-১৫০ MB এর বেশি RAM ব্যবহার না করে, সেজন্য রিসোর্স থ্রটলিং (Resource Throttling) কীভাবে কনফিগার করবে?
22. এন্ডপয়েন্টে কোনো অ্যাপ্লিকেশন হঠাৎ লাখ লাখ লগ তৈরি করলে (Log Storm) এজেন্টের কারণে যাতে পুরো অপারেটিং সিস্টেম ফ্রিজ না হয়, সেজন্য ইভেন্ট রেট-লিমিটিং (`events_per_second` at agent level) কীভাবে সেট করবে?
23. এজেন্টের নেটওয়ার্ক ব্যান্ডউইথ ব্যবহার সীমিত রাখতে (Bandwidth Throttling / Rate-limiting) এবং WAN লিঙ্কের স্যাচুরেশন এড়াতে কোন কনফিগারেশন প্রয়োগ করবে?
24. লিনাক্সে এজেন্টের প্রসেস প্রায়োরিটি কমাতে `nice` এবং `ionice` (I/O scheduling class: idle/best-effort) কীভাবে ব্যবহার করবে যাতে প্রোডাকশন ডেটাবেজ বা সার্ভিসের ডিস্ক I/O ব্যাহত না হয়?
25. এজেন্ট ক্র্যাশ লুপে পড়লে (Crash-LoopBackOff) বা মেমোরি লিক দেখা দিলে সিস্টেমড ওয়াচডগ বা হোস্ট সেলফ-হিলিং সার্ভিস কীভাবে এজেন্টকে সেফটি রিস্টার্ট করাবে?

### Topic 06: Local Disk Buffering & Network Disconnection Resiliency

26. ইন্টারনেট বা লোকাল নেটওয়ার্ক ড্রপ হলে এজেন্ট কীভাবে তার নিজস্ব লোকাল ডিস্ক বাফারে (Spooler / Disk Queue) ইভেন্টগুলো সংরক্ষণ করে?
27. এজেন্টের লোকাল ডিস্ক বাফার সাইজ (যেমন: ৫০০ MB বা ১ GB) নির্ধারণের সঠিক গাণিতিক সূত্র কী যাতে ক্লায়েন্ট ডিস্কের স্পেস শেষ না হয় আবার লগও নষ্ট না হয়?
28. দীর্ঘ নেটওয়ার্ক আউটেজের পর বাফার পূর্ণ হয়ে গেলে নতুন ইভেন্ট আসলে ডিফল্ট বিহেভিয়র কী হবে—পুরানো ইভেন্ট ড্রপ হবে (FIFO/Tail-drop) নাকি নতুন ইভেন্ট বন্ধ থাকবে এবং কোনটি সিকিউরিটির জন্য যৌক্তিক?
29. নেটওয়ার্ক পুনরায় চালু হলে এজেন্ট জমাকৃত ব্যাকলগ সার্ভারে পাঠানোর সময় যাতে নেটওয়ার্ক পাইপলাইন প্লাড না করে, সেজন্য ব্যাকলগ ড্রেনিং রেট কীভাবে কন্ট্রোল করবে?
30. হঠাৎ হোস্ট পাওয়ার অফ বা আনএক্সপেক্টেড রিবুট হলেও এজেন্টের ডিস্ক বাফারে থাকা ডেটা যেন করাপ্ট না হয়, তার মেকানিজম কী?

### Topic 07: Remote Agent Upgrades & Lifecycle Management

31. শত শত রিমোট এজেন্টে ফিজিক্যাল বা ম্যানুয়াল অ্যাক্সেস ছাড়াই সেন্ট্রাল ম্যানেজার থেকে রিমোট সাইড দিয়ে ব্যাচ-ওয়াইজ এজেন্ট আপগ্রেড (Remote Agent Upgrade) কীভাবে চালাবে?
32. আপগ্রেড করার সময় নেটওয়ার্ক ড্রপ হলে বা প্যাকেজ কারাপ্ট হলে এজেন্ট স্বয়ংক্রিয়ভাবে তার পূর্ববর্তী স্টেবল ভার্সনে রোলব্যাক (Automatic Rollback) করে কীভাবে সার্ভিস চালু রাখবে?
33. প্রোডাকশনে একবারে ৫০০টি এজেন্টে আপগ্রেড না চালিয়ে কীভাবে ক্যানারি ডিপ্লয়মেন্ট (প্রথমে টেস্ট ল্যাবে, তারপর ৫% সিস্টেমে, অতঃপর ধাপে ধাপে পুরো এন্টারপ্রাইজে) পরিচালনা করবে?
34. লিগ্যাসি অপারেটিং সিস্টেম (যেমন: Windows Server 2008 বা CentOS 6) থাকলে নতুন এজেন্ট ভার্সনের সাথে ব্যাকওয়ার্ড কম্প্যাটিবিলিটি কীভাবে বজায় রাখবে?
35. এজেন্ট আনইনস্টল বা ডিসকমিশন করার সময় হোস্ট সিস্টেমের রেজিস্ট্রি, লগ ও কনফিগারেশন ফাইল সম্পূর্ণ ক্লিন করার অটোমেশন পদ্ধতি কী?

### Topic 08: Agent Connectivity Troubleshooting & Communication Edge Cases

36. একটি এন্ডপয়েন্টে এজেন্ট সফলভাবে ইনস্টল হয়েছে এবং সার্ভিস রান করছে, কিন্তু SIEM ম্যানেজারে ‘Disconnected’ বা ‘Never Connected’ দেখাচ্ছে—ধাপে ধাপে কীভাবে এর রুট কজ শনাক্ত করবে?
37. ক্লায়েন্ট এবং ম্যানেজারের মধ্যে নেটওয়ার্ক ফায়ারওয়াল বা NAT Gateway থাকলে পোর্ট 1514 (TCP/UDP) ড্রপ হচ্ছে কিনা তা `nc`, `tcpdump` বা `Test-NetConnection` দিয়ে কীভাবে ডায়াগনসিস করবে?
38. MTU মিসম্যাচের কারণে এজেন্ট রেজিস্ট্রেশন সফল হলেও লার্জ লগ প্যাকেট পাঠাতে গিয়ে প্যাকেট ড্রপ বা সাইলেন্ট কানেকশন ড্রপ হলে কীভাবে তা শনাক্ত ও সমাধান করবে?
39. এন্টারপ্রাইজ প্রক্সি সার্ভার বা SSL-Inspection ফায়ারওয়াল থাকলে এজেন্টের mTLS এনক্রিপশন ট্রাফিক ব্লক বা করাপ্ট হওয়া কীভাবে এড়াবে?

### Topic 09: Asset Inventory Reconciliation & Coverage Auditing
