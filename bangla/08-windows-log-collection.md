# 08 — Windows Log Collection

## SIEM Engineer Interview Questions

### Topic 01: Windows Event Log Architecture & Subsystems

1. আধুনিক উইন্ডোজ অপারেটিং সিস্টেমে Windows Event Log (EVTX) আর্কিটেকচার কীভাবে কাজ করে এবং ক্লাসিক্যাল চ্যানেল (Security, System, Application) বনাম অ্যাপস/সার্ভিসেস চ্যানেলের (Microsoft-Windows-*) মধ্যকার কাঠামোগত পার্থক্য কী?
2. উইন্ডোজ ইভেন্ট লগ কীভাবে বাইনারি XML ফরম্যাটে স্টোর হয় এবং এজেন্ট যখন এই লগ রিড করে তখন ডাইনামিক ফিল্ড এক্সট্রাকশন (EventData vs System Data) কীভাবে কার্যকর হয়?
3. Event Viewer-এর চ্যানেল বাফার সাইজ (Maximum Log Size) এবং রিটেনশন পলিসি ("Overwrite events as needed" বনাম "Archive the log when full") কীভাবে কনফিগার করা উচিত যাতে কোনো সিকিউরিটি ইভেন্ট ওভাররাইট হয়ে চিরতরে হারিয়ে না যায়?
4. একটি সাধারণ উইন্ডোজ ওয়ার্কস্টেশন বনাম একটি ডোমেন কন্ট্রোলারে দৈনিক কত মেগাবাইট বা গিগাবাইট ইভেন্ট লগ জেনারেট হতে পারে এবং তার সঠিক পরিমাপ কীভাবে করবে?
5. কোনো কারণে Windows Event Log সার্ভিস (`eventlog`) ক্র্যাশ বা ম্যানুয়ালি স্টপ করা হলে সিস্টেমে তার ইমপ্যাক্ট কী এবং SIEM কীভাবে তা তাৎক্ষণিক ক্যাচ করবে?

### Topic 02: Advanced Security Audit Policy Configuration

6. উইন্ডোজে ডিফল্ট বেসিক অডিটিং কেন এন্টারপ্রাইজ সিকিউরিটির জন্য সম্পূর্ণ অপর্যাপ্ত এবং Group Policy (GPO) দিয়ে Advanced Audit Policy Configuration কেন বাধ্যতামূলকভাবে প্রয়োগ করতে হয়?
7. Account Logon (ইভেন্ট ৪৬২৪, ৪৬২৫), Account Management (ইভেন্ট ৪৭২০, ৪৭২৪, ৪৭৩৮), এবং Privilege Use (ইভেন্ট ৪৬৭২, ৪৬৭৩)-এর ক্ষেত্রে Success এবং Failure অডিটিংয়ের সঠিক কনফিগারেশন কী?
8. "Audit Process Creation" এবং কমান্ড-লাইন আর্গুমেন্ট ট্র্যাকিং ("Include command line in process creation events" - Event ID 4688) কনফিগার করার সিকিউরিটি গুরুত্ব কী এবং এটি কীভাবে কার্যকর করবে?
9. "Audit Object Access" পলিসির মাধ্যমে ফাইল সার্ভারের শেয়ারে থাকা কোনো গোপন ফাইল বা ফোল্ডারে রিড/রাইট/ডিলিট এক্টিভিটি ট্র্যাক করতে ফাইল সিস্টেমে SACL (System Access Control List) কীভাবে কনফিগার করবে?
10. অপ্রয়োজনীয় অডিট পলিসি (যেমন: প্রতি সেকেন্ডে হাজার হাজার সাকসেসফুল নেটওয়ার্ক কানেকশন অডিট ৪৬৫৮) চালু করার কারণে ডোমেন কন্ট্রোলার ফ্রিজ হওয়া বা লগ ফ্লাড হওয়া কীভাবে রোধ করবে?

### Topic 03: Sysmon Architecture & Modular Configuration

11. মাইক্রোসফটের Sysinternals Sysmon কী এবং এটি উইন্ডোজের কোন লেভেলে (কার্নেল ডিভাইস ড্রাইভার মডিউল) বসে কাজ করে?
12. সাধারণ উইন্ডোজ সিকিউরিটি ইভেন্ট ৪৬৮৮ থাকার পরেও Sysmon Event ID 1 (Process Creation with Hashes, ParentProcessId, CommandLine) কেন ডিটেকশন ইঞ্জিনিয়ারদের জন্য গেম-চেঞ্জার?
13. Sysmon-এর গুরুত্বপূর্ণ ইভেন্ট আইডিগুলো: Network Connection (Event ID 3), Driver Loaded (Event ID 6), Image Loaded (Event ID 7), Process Access / Mimikatz injection (Event ID 10), এবং File Create (Event ID 11)-এর ভূমিকা ব্যাখ্যা কর।
14. প্রোডাকশনে সুইফট-অন-সিকিউরিটি (SwiftOnSecurity) বা ওলাফ হার্টং (Olaf Hartong)-এর মডুলার Sysmon XML কনফিগারেশন ব্যবহারের সুবিধা কী এবং অপ্রয়োজনীয় ব্রাউজার ট্রাফিক ফিল্টার আউট করার কৌশল কী?
15. Sysmon Event ID 22 (DNS Query) চালু করলে ডোমেন কন্ট্রোলার বা ক্লায়েন্ট মেশিনে DNS টানেলিং ও ম্যালিসিয়াস ডোমেন রিকোয়েস্ট ট্র্যাক করার পদ্ধতি এবং এর ভলিউম ওভারহেড কীভাবে সামলাবে?

### Topic 04: PowerShell Auditing, Script Block & Transcription

16. সাইবার অ্যাটাকাররা ফাইললেস ম্যালওয়্যার ও মেমোরি-বেসড অ্যাটাকের জন্য পাওয়ারশেল ব্যবহার করলে তা ডিটেক্ট করতে কোন ৩টি অডিটিং পলিসি (Module Logging, Script Block Logging, Transcription) কনফিগার করতে হয়?
17. PowerShell Script Block Logging (Event ID 4104) কীভাবে অফাসকেটেড (Obfuscated / Base64 Encoded) কোড মেমোরিতে ডিকোড হওয়ার পর আনপ্যাকড স্ক্রিপ্ট ক্যাপচার করতে পারে?
18. PowerShell Transcription পলিসি চালু করার পর তৈরি হওয়া ট্রান্সক্রিপ্ট টেক্সট ফাইলগুলো সেন্ট্রালাইজডভাবে সুরক্ষিত রাখা এবং SIEM এজেন্টের মাধ্যমে ইনজেস্ট করার কনফিগারেশন কী?
19. PowerShell Version 2.0 (যা মডার্ন স্ক্রিপ্ট ব্লক লগিং বাইপাস করতে অ্যাটাকাররা ব্যবহার করে) সিস্টেম থেকে কীভাবে সম্পূর্ণ রিমুভ বা অডিট করবে?
20. PowerShell 7 (PowerShell Core) লিনাক্স বা উইন্ডোজে ইনস্টল থাকলে তার লগ চ্যানেল এবং কনফিগারেশন ট্র্যাডিশনাল উইন্ডোজ পাওয়ারশেল থেকে কীভাবে আলাদা?

### Topic 05: Active Directory & Domain Controller Log Collection

21. অ্যাক্টিভ ডিরেক্টরি ডোমেন কন্ট্রোলার (DC) থেকে কালেকশনের জন্য অত্যন্ত গুরুত্বপূর্ণ ইভেন্ট আইডিগুলো: Kerberos Ticket Request (4768), Service Ticket Request (4769), Pre-Auth Failure / Kerberoasting (4771) কেন নজরদারিতে রাখা প্রয়োজন?
22. প্রিভিলেজড গ্রুপ পরিবর্তন (Domain Admins, Enterprise Admins-এ ইউজার অ্যাড: Event ID 4728, 4732) এবং গ্রুপ পলিসি অবজেক্ট (GPO) মডিফিকেশন (Event ID 5136, 5137) কীভাবে রিয়েল-টাইমে সংগ্রহ করবে?
23. ডোমেন ব্যাকআপ বা NTDS.dit ডেটাবেজ এক্সট্রাক্ট করার মতো মারাত্মক অ্যাটাক (Volume Shadow Copy / DCSync) ট্র্যাক করতে কোন ডিরেক্টরি সার্ভিস এক্সেস ইভেন্টগুলো মনিটর করতে হবে?
24. ডোমেন কন্ট্রোলারে হাই ভলিউম ইভেন্ট আসার কারণে এজেন্টের রিসোর্স ব্যবহার সীমিত রাখতে শুধুমাত্র সিকিউরিটি-ক্রিটিক্যাল চ্যানেল ফিল্টার করে ইনজেস্ট করার পদ্ধতি কী?
25. ডোমেন ট্রাস্ট পরিবর্তন, কার্বেরোস গোল্ডেন/সিলভার টিকিট অ্যাটাক ডিটেকশনের জন্য DC ক্লক সিনক্রোনাইজেশনের ভূমিকা কী?

### Topic 06: Event Channel Filtering, XPath Queries & Noise Suppression

26. উইন্ডোজ থেকে অপ্রয়োজনীয় নয়েজ কমিয়ে ক্লাউড বা অন-প্রিম ইনজেশন খরচ বাঁচাতে এজেন্টের কনফিগারেশনে XPath কুয়েরি (`<QueryList>`) কীভাবে ব্যবহার করবে?
27. উদাহরণসহ একটি XPath ফিল্টার লিখ যা শুধুমাত্র Event ID 4624, 4625, 4688, 4720 এবং 4728 ফিল্টার করে আনবে এবং বাকিসব সিস্টেম লেভেলেই ড্রপ করবে।
28. ব্যাকগ্রাউন্ড উইন্ডোজ সিস্টেম সার্ভিস একাউন্ট (যেমন: `NT AUTHORITY\SYSTEM`, `LOCAL SERVICE`) দ্বারা সৃষ্ট হাজার হাজার সাধারণ লগইন লগ কীভাবে ফিল্টার আউট করবে যাতে আসল ইউজার ট্রাফিক স্পষ্ট থাকে?
29. ড্রপড ইভেন্ট ট্র্যাকিং: ফিল্টারিংয়ের কারণে কোনো জেনুইন সিকিউরিটি ইভেন্ট মিস হচ্ছে কিনা তা পিরিয়ডিক্যালি ভ্যালিডেট করার পদ্ধতি কী?
30. বিভিন্ন ডিপার্টমেন্টের মেশিনের জন্য আলাদা আলাদা উইন্ডোজ লগ প্রোফাইল (Minimal Profile vs Forensic Profile) কনফিগারেশন কীভাবে তৈরি করবে?

### Topic 07: Windows Event Forwarding (WEF) & Collector (WEC) Architecture

31. এন্ডপয়েন্টগুলোতে কোনো থার্ড-পার্টি এজেন্ট ইনস্টল না করে নেটিভ Windows Event Forwarding (WEF) এবং Windows Event Collector (WEC) ব্যবহার করে সেন্ট্রালাইজড লগ কালেকশন কীভাবে ডিজাইন করবে?
32. ডোমেন এনভায়রনমেন্টে WinRM (Windows Remote Management) সার্ভিস, Kerberos অথেনটিকেশন এবং Group Policy ব্যবহার করে পুশ বনাম পুল সাবস্ক্রিপশন কীভাবে কনফিগার করবে?
33. WEC সার্ভারে হাজার হাজার মেশিনের ট্রাফিক একত্রিত হওয়ার পর সেখান থেকে SIEM ইঞ্জিনে লগ ফরোয়ার্ড করার নির্ভরযোগ্য মেকানিজম কী?
34. নন-ডোমেন joined বা রিমোট উইন্ডোজ মেশিনের ক্ষেত্রে মিউচুয়াল সার্টিফিকেট (HTTPS) ব্যবহার করে WEC সাবস্ক্রিপশন কনফিগার করার চ্যালেঞ্জ ও সমাধান কী?
35. WEF/WEC আর্কিটেকচারের সুবিধা (নো থার্ড পার্টি এজেন্ট, নেটিভ উইন্ডোজ সার্ভিস) বনাম সীমাবদ্ধতা (একক ফেইলিওর পয়েন্ট, নো অ্যাক্টিভ রেসপন্স) কীভাবে মূল্যায়ন করবে?

### Topic 08: Specialized Windows Logs: Defender, Firewall & DNS

36. Windows Defender Antivirus / Defender for Endpoint-এর ডিটেকশন লগ (Event ID 1116 - Threat Detected, 1117 - Threat Remediated) এবং এক্সক্লুশন পরিবর্তন ট্র্যাক করার চ্যানেল কনফিগারেশন কী?
37. Windows Filtering Platform (WFP / Windows Advanced Firewall)-এর ব্লকড কানেকশন (Event ID 5157) এবং ড্রপড প্যাকেট লগ কীভাবে কোনো পারফরম্যান্স ক্ষতি ছাড়াই ইনজেস্ট করবে?
38. উইন্ডোজ সার্ভারের ফাইল-বেসড DHCP Audit Logs (`%SystemRoot%\System32\dhcp\DhcpSrvLog-*.log`) থেকে আইপি রেন্ট ও ম্যাক অ্যাড্রেস ম্যাপিং কীভাবে এজেন্টের মাধ্যমে কালেক্ট করবে?
39. এন্টারপ্রাইজ উইন্ডোজ DNS সার্ভার থেকে DNS Debug Logging বা Analytical Event Channel কীভাবে সিস্টেমে অতিরিক্ত সিপিইউ ব্যবহার না করে সুরক্ষিতভাবে রিড করবে?
40. ইন্টারনেট ইনফরমেশন সার্ভিসেস (IIS Web Server) থেকে W3C ফরম্যাটের ওয়েব রিকোয়েস্ট লগ কালেকশন ও রিয়েল-টাইম স্ট্রিমিং কনফিগারেশন কীভাবে করবে?

### Topic 09: Log Ingestion Integrity, Dropped Events & Anti-Forensics

41. সাইবার অ্যাটাকাররা কম্প্রোমাইজ করার পর তাদের ফুটপ্রিন্ট ঢাকতে উইন্ডোজ ইভেন্ট লগ মুছে দিলে Event ID 1102 ("The audit log was cleared") কীভাবে সিস্টেমের সর্বোচ্চ প্রায়োরিটি দিয়ে ক্যাপচার করবে?
