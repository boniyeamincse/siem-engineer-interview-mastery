# 06 — SIEM Component Configuration

## SIEM Engineer Interview Questions

### Topic 01: Component Decoupling & Installation Sequence

1. একটি ডিস্ট্রিবিউটেড এন্টারপ্রাইজ SIEM-এ Manager, Indexer, Dashboard এবং Syslog Collector-কে আলাদা আলাদা সার্ভারে কনফিগার করার সময় ডিপ্লয়মেন্ট সিকোয়েন্স (কোন কম্পোনেন্ট আগে এবং কোনটি পরে চালু করতে হবে) কীভাবে নির্ধারণ করবে এবং কেন?
2. ইনডেক্সার ক্লাস্টার সম্পূর্ণরূপে ইনিশিয়ালাইজ ও গ্রিন স্টেটে যাওয়ার পূর্বেই ম্যানেজার সার্ভিস চালু করলে কী ধরনের বাফারিং সমস্যা বা ডেটা লস হতে পারে?
3. সিঙ্গেল-নোড অল-ইন-ওয়ান আর্কিটেকচার থেকে মাল্টি-নোড ডিস্ট্রিবিউটেড আর্কিটেকচারে কনফিগারেশন মাইগ্রেট করার সময় প্রতিটি কম্পোনেন্টের বাইন্ডিং আইপি (`bind_address`, `network.host`) কীভাবে আলাদা করবে?
4. কম্পোনেন্টগুলোর সার্ভিস পোর্ট (ম্যানেজার: 1514/1515, ইনডেক্সার: 9200/9300, ড্যাশবোর্ড: 5601/443, এপিআই: 55000 ইত্যাদি) লিনাক্স ওএস ও নেটওয়ার্ক ফায়ারওয়ালে কীভাবে সেগমেন্টেড কনফিগারেশনে উন্মুক্ত করবে?
5. সার্ভার রিবুট বা পাওয়ার আউটেজের পর সিস্টেমড ডিপেন্ডেন্সি অর্ডার (`After=`, `Requires=`, `Wants=`) ব্যবহার করে কম্পোনেন্টগুলোর স্বয়ংক্রিয় স্টার্টআপ সিকোয়েন্স কীভাবে নিয়ন্ত্রণ করবে?

### Topic 02: Mutual TLS (mTLS) & Certificate Authority Engineering

6. SIEM-এর সকল কম্পোনেন্টের মধ্যকার কমিউনিকেশন (Agent-to-Manager, Manager-to-Indexer, Dashboard-to-Indexer) সুরক্ষিত করতে একটি ডেডিকেটেড ইন্টারনাল Certificate Authority (Root CA ও Intermediate CA) কীভাবে জেনারেট করবে?
7. নোড-টু-নোড কমিউনিকেশনের জন্য Mutual TLS (mTLS) কনফিগার করার প্রয়োজনীয়তা কী এবং ক্লায়েন্ট ও সার্ভার উভয় প্রান্তেই সার্টিফিকেট ভ্যালিডেশন কীভাবে নিশ্চিত করবে?
8. ওয়াইল্ডকার্ড সার্টিফিকেট (`*.domain.local`) ব্যবহার করার চেয়ে প্রতিটি নোডের জন্য স্বতন্ত্র Subject Alternative Name (SAN - FQDN এবং IP) সহ নোড সার্টিফিকেট ইস্যু করা কেন বেশি নিরাপদ?
9. প্রোডাকশনে কোনো একটি নোডের সার্টিফিকেট এক্সপায়ার হয়ে গেলে পুরো পাইপলাইন যাতে বন্ধ না হয়, সেজন্য রিমোট সার্টিফিকেট এক্সপিরেশন ট্র্যাকিং এবং জিরো-ডাউনটাইম সার্টিফিকেট রোটেশন কীভাবে কনফিগার করবে?
10. ওপেন-সোর্স ইউটিলিটি (যেমন: Wazuh certs tool, OpenSearch `securityadmin.sh`, Elastic `elasticsearch-certutil`) ব্যবহার করে তৈরি করা সার্টিফিকেটের প্রাইভেট কি-এর অনুমতি (`chmod 600`, `chown`) কীভাবে লিনাক্সে লক করবে?

### Topic 03: SIEM Manager & Engine Architecture

11. SIEM Manager ক্লাস্টারে Master Node এবং Worker Node-এর মধ্যে রোল কীভাবে ভাগ করবে এবং ওয়ার্কার নোডগুলোর মধ্যে ফাইল সিঙ্ক (`cluster.json`, কাস্টম রুলস, ডিকোডার, সিবিডি ফাইল) কীভাবে পরিচালিত হয়?
12. ইনকামিং এজেন্ট কানেকশন এবং ইভেন্ট প্রসেসিংয়ের জন্য ম্যানেজারের সকেট বাফার (`remoted` queue size, `analysisd` queue size) কীভাবে কনফিগার করবে যাতে হাই ট্রাফিকের সময় মেমোরি ড্রপ না ঘটে?
13. ম্যানেজারের গ্লোবাল কনফিগারেশন ফাইলে (`ossec.conf`) লগ লেভেল, ডিবাগ মোড, অ্যালার্টিং থ্রেশহোল্ড এবং ইমেইল/ওয়েবহুক নোটিফিকেশন ইঞ্জিন কীভাবে সুরক্ষিতভাবে সেটআপ করবে?
14. ম্যানেজারের নিজস্ব ডেটাবেজ বা ফাইল ব্যাকএন্ডে কানেক্টেড এজেন্টদের স্টেট টেবিল (`client.keys`, agent status database) কীভাবে করাপশন থেকে সুরক্ষিত রাখবে?
15. মাল্টি-ম্যানেজার ক্লাস্টারে সক্রিয় মাস্টার নোড ক্র্যাশ করলে ওয়ার্কার নোডগুলো কীভাবে লোকাল ক্যাশে কাজ চালিয়ে যায় এবং স্প্লিট-ব্রেন (Split-Brain) পরিস্থিতি কীভাবে প্রতিরোধ করে?

### Topic 04: SIEM Indexer & Cluster Node Engineering

16. একটি ৩-নোড ইনডেক্সার ক্লাস্টারে Master-Eligible Node, Data Node এবং Coordinating/Ingest Node-এর ভূমিকা কীভাবে কনফিগারেশন ফাইলে (`opensearch.yml` বা `elasticsearch.yml`) সংজ্ঞায়িত করবে?
17. ক্লাস্টারে কোরাম (Quorum) নিশ্চিত করতে এবং স্প্লিট-ব্রেন সিন্ড্রোম চিরতরে বন্ধ করতে ভোটিং কনফিগারেশন (`cluster.initial_master_nodes`, `discovery.seed_hosts`) কীভাবে সেট করবে?
18. ডাটা নোডে শার্ড ডিস্ট্রিবিউশন এবং রাইট থ্রেডপুল (`thread_pool.write.queue_size`) কীভাবে টিউন করবে যাতে হেভি ইনজেশনের সময় `429 Too Many Requests (EsRejectedExecutionException)` এরর না আসে?
19. ইনডেক্সিং স্পিড ও ডেটা ডিউরেবিলিটির মধ্যে ব্যালান্স রাখতে `index.translog.durability: async` এবং `index.refresh_interval: 30s` কনফিগার করার সুবিধা ও সম্ভাব্য ঝুঁকি কী?
20. ইন্টারনাল সিকিউরিটি প্লাগইন ইনিশিয়ালাইজ করতে এবং অ্যাডমিন শংসাপত্র আপডেট করতে অ্যাডমিন সিএলআই স্ক্রিপ্ট (যেমন `securityadmin.sh`) ব্যবহারের সঠিক পদ্ধতি ও সতর্কতা কী?

### Topic 05: Index Lifecycle Management (ILM / ISM) & Templates

21. প্রতিদিন স্বয়ংক্রিয়ভাবে ইনডেক্স তৈরি, সাইজ অনুযায়ী রোল-ওভার এবং স্টোরেজ ফেজ নির্ধারণের জন্য Index State Management (ISM) বা Index Lifecycle Management (ILM) পলিসি কীভাবে তৈরি করবে?
22. Hot Phase (ইনজেশন ও দ্রুত সার্চ: NVMe), Warm Phase (সার্চেবল কিন্তু কম অ্যাক্টিভ: SSD) এবং Cold/Delete Phase (রিটেনশন এক্সপায়ার হলে ডিলিট বা এস৩ আর্কাইভ)-এর ট্রানজিশন রুল কীভাবে কনফিগার করবে?
23. ইনডেক্স প্যাটার্ন এবং ডায়নামিক ফিল্ড ম্যাপিং কন্ট্রোল করতে একটি প্রোডাকশন "Index Template" কীভাবে ডিজাইন করবে, যাতে নতুন ফিল্ড ঢুকলে ইনডেক্স স্প্রল (Mapping Explosion) না ঘটে?
24. প্রাইমারি শার্ড সাইজ সাধারণত ৩০ GB থেকে ৫০ GB-এর মধ্যে রাখতে কেন পরামর্শ দেওয়া হয় এবং এই নিয়মের ভিত্তিতে অটো-রোলওভার পলিসি (`max_primary_shard_size: 50gb`, `max_age: 30d`) কীভাবে কনফিগার করবে?
25. রিটেনশন পিরিয়ড শেষ হওয়ার পর স্বয়ংক্রিয়ভাবে শার্ড ডিলিটেশন পলিসি ফেইল করলে এবং ডিস্ক পূর্ণ হতে থাকলে পলিসি এরর কীভাবে ডিবাগ ও সংশোধন করবে?

### Topic 06: Dedicated Collector & Forwarder Configuration

26. একটি ডেডিকেটেড সিসলগ কালেক্টর (যেমন: Rsyslog, Logstash, Vector বা Fluentbit) কনফিগার করার সময় TCP এবং UDP উভয় প্রটোকলের জন্য বাফারিং ও প্রসেসিং পাইপলাইন কীভাবে সাজাবে?
27. Rsyslog-এ মেমোরি বাফার এবং ডিস্ক-অ্যাসিস্টেড পারসিস্টেন্ট কিউ (`$ActionQueueType LinkedList`, `$ActionQueueFileName`) কীভাবে কনফিগার করবে যাতে ডাউনস্ট্রিম SIEM ডাউন থাকলেও কালেক্টর ডিস্কে লগ জমে থাকে?
28. ফায়ারওয়াল বা প্রক্সি থেকে আসা অপরিস্কার ও ভলিউমিনাস লগ কালেক্টর লেভেলেই ড্রপ (Drop / Discard rules) বা ফিল্টার করার জন্য পাইপলাইন রুলস কীভাবে লিখবে?
29. কালেক্টর সার্ভার নিজে যাতে বটলনেক না হয়, সেজন্য মাল্টি-থ্রেডেড ইনপুট ও আউটপুট ওয়ার্কার কনফিগারেশন কীভাবে করবে?
30. কালেক্টর থেকে মূল SIEM ম্যানেজারে বা ইনডেক্সারে লগ পাঠানোর সময় TLS মিউচুয়াল এনক্রিপশন এবং কম্প্রেশন কীভাবে সক্রিয় করবে?

### Topic 07: Web UI & Dashboard Engine Configuration

31. ড্যাশবোর্ড সার্ভার (OpenSearch Dashboards / Kibana / Wazuh Dashboard)-এর কনফিগারেশন ফাইলে ব্যাকএন্ড ইনডেক্সার ক্লাস্টারের একাধিক নোড URL (`opensearch.hosts`) কীভাবে রিডানড্যান্টভাবে উল্লেখ করবে?
32. ড্যাশবোর্ডে সরাসরি HTTP ট্রাফিক বন্ধ করে স্বয়ংক্রিয় HTTPS রিডাইরেকশন এবং কাস্টম SSL/TLS সার্টিফিকেট কীভাবে ইন্টিগ্রেট করবে?
33. ড্যাশবোর্ডের ফ্রন্টে Nginx বা HAProxy রিভার্স প্রক্সি কনফিগার করার সুবিধা কী এবং প্রক্সির মাধ্যমে সিকিউরিটি হেডার্স (HSTS, CSP, X-Frame-Options) কীভাবে এনফোর্স করবে?
34. ড্যাশবোর্ডের কুকি সেশন ম্যানেজমেন্ট, আইডল সেশন টাইমআউট এবং ব্রাউজার ক্যাশিং কীভাবে এন্টারপ্রাইজ কমপ্লায়েন্স অনুযায়ী কনফিগার করবে?
35. ড্যাশবোর্ড যদি ইনডেক্সারের সাথে কানেক্ট হতে না পারে এবং "Server Not Ready Yet" বা "Cluster Red" দেখায়, তবে ব্যাকএন্ড কমিউনিকেশন ও কি-স্টোর কীভাবে পরীক্ষা করবে?

### Topic 08: API Connectivity, Authentication & Secrets

36. SIEM ম্যানেজারের RESTful API সার্ভিসের কনফিগারেশনে অ্যাডমিন ক্রেডেনশিয়াল সুরক্ষিত রাখা, ডিফল্ট পোর্ট পরিবর্তন এবং বাইন্ড অ্যাড্রেস কীভাবে সীমিত করবে?
37. API রিকোয়েস্টের জন্য JSON Web Token (JWT) জেনারেশন, টোকেন এক্সপিরেশন টাইম এবং রিফ্রেশ টোকেন পলিসি কীভাবে কনফিগার করবে?
38. কনফিগারেশন ফাইলগুলোতে (যেমন `kibana.yml` বা `opensearch.yml`) প্লেইন-টেক্সট পাসওয়ার্ড লেখার বদলে সিকিউর কি-স্টোর (`opensearch-keystore`, `kibana-keystore`) কীভাবে ব্যবহার করবে?
39. অটোমেশন স্ক্রিপ্ট ও থার্ড-পার্টি টুলের (SOAR, Ticketing) জন্য ডেডিকেটেড সার্ভিস একাউন্ট তৈরি করে Role-Based Access Control (RBAC) দিয়ে নির্দিষ্ট এন্ডপয়েন্টে অ্যাক্সেস কীভাবে রেস্ট্রিক্ট করবে?

### Topic 09: Component Health, Heartbeats & Diagnostics
