# 11 — Application Log Integration

## SIEM Engineer Interview Questions

### Topic 01: Application Log Formats & Modern Ingestion Architecture

1. এন্টারপ্রাইজ কাস্টম অ্যাপ্লিকেশনগুলোর লগিং ফরম্যাট (স্ট্রাকচার্ড JSON, Key-Value Pair, CSV, আনস্ট্রাকচার্ড প্লেইন টেক্সট এবং মাল্টিলাইন স্ট্যাক ট্রেস)-এর মধ্যে ইনজেশন ও পার্সিং পারফরম্যান্সের টেকনিক্যাল পার্থক্য কী?
2. আধুনিক সফটওয়্যার আর্কিটেকচারে সরাসরি ফাইল রাইট করার বদলে কন্সোল (stdout/stderr) লগিং বনাম নেটওয়ার্ক সকেট (TCP/UDP) বা সরাসরি মেসেজ কিউতে (Kafka/RabbitMQ) লগ পাঠানোর সুবিধা-অসুবিধা কী?
3. JSON ফরম্যাটের লগ সরাসরি ইনজেস্ট করার সুবিধা কী এবং যখন কোনো ডেভেলপার নেস্টেড বা রিকার্সিভ JSON অবজেক্ট (Deeply nested JSON) পাঠায়, তখন ইনডেক্সারের ম্যাপিং এক্সপ্লোশন কীভাবে প্রতিরোধ করবে?
4. একটি অ্যাপ্লিকেশনের প্রতিদিন কোটি কোটি লগ লাইন তৈরি হলে অ্যাপ্লিকেশনের নিজস্ব পারফরম্যান্সে কোনো ল্যাগ (I/O Blocking) তৈরি না করে অ্যাসিঙ্ক্রোনাস লগিং (Asynchronous Logging) কীভাবে নিশ্চিত করবে?
5. কোনো আনডকুমেন্টেড লিগ্যাসি অ্যাপ্লিকেশনের লগিং মেকানিজম রিভার্স-ইঞ্জিনিয়ারিং করে কীভাবে তার লগ ফরম্যাট ও ইনজেশন পাইপলাইন ডিজাইন করবে?

### Topic 02: Web Servers & Reverse Proxies (Nginx, Apache, HAProxy)

6. Nginx এবং Apache HTTPD ওয়েব সার্ভারের এক্সেস লগ (Access Log) এবং এরর লগ (Error Log)-এর ডিফল্ট কম্বাইন্ড ফরম্যাট (Combined Log Format)-এর সীমাবদ্ধতা কী এবং কেন কাস্টম JSON ফরম্যাটে লগ রিলিজ করা উচিত?
7. ওয়েব সার্ভার লগে ক্লায়েন্টের আসল আইপি প্রিজার্ভ করতে `X-Forwarded-For` এবং `X-Real-IP` হেডারের পার্সিং কীভাবে নিশ্চিত করবে (বিশেষ করে ক্লাউডফ্লেয়ার বা রিভার্স প্রক্সির পেছনে থাকলে)?
8. ওয়েব অ্যাপ্লিকেশন অ্যাটাক (যেমন: SQL Injection, Cross-Site Scripting, Path Traversal, Directory Bruteforce) ডিটেক্ট করতে ওয়েব লগের কোন কোন ফিল্ড (URI, Query Parameters, HTTP Method, Response Code, User-Agent, Bytes Sent) অত্যন্ত ক্রিটিক্যাল?
9. HAProxy বা ক্লাউড লোড ব্যালান্সারের সিসলগ স্ট্রিমিং কনফিগারেশন এবং আপস্ট্রিম সার্ভার রেসপন্স টাইম (Response Latency) ট্র্যাকিং কীভাবে কার্যকর করবে?
10. ওয়েব সার্ভারে হাই ট্রাফিকের সময় হাজার হাজার `HTTP 200 OK` স্ট্যাটিক ফাইল (ইমেজ, সিএসএস, জেএস) রিকোয়েস্ট যাতে SIEM-এ নয়েজ না বাড়ায়, সেজন্য ওয়েব সার্ভার লেভেলেই স্ট্যাটিক ফাইল লগিং ড্রপ করার কনফিগারেশন কী?

### Topic 03: Database Management Systems (PostgreSQL, MySQL, MSSQL, Oracle)

11. রিলেশনাল ডেটাবেজ ম্যানেজমেন্ট সিস্টেমে (RDBMS) সাধারণ কোয়েরি লগের সাথে সিকিউরিটি অডিট লগের (Audit Log / Compliance Log) পার্থক্য কী এবং কেন সব সিলেক্ট কোয়েরি লগ করা উচিত নয়?
12. PostgreSQL-এ `pgaudit` এক্সটেনশন ব্যবহার করে ডেটা ডেফিনিশন ল্যাঙ্গুয়েজ (DDL: `CREATE`, `DROP`, `ALTER`), ডেটা ম্যানিপুলেশন (DML: `UPDATE`, `DELETE`) এবং পারমিশন গ্রান্ট কীভাবে নিখুঁতভাবে লগ করবে?
13. ডেটাবেজে প্রিভিলেজড ইউজার এক্টিভিটি (যেমন: `postgres`, `sa` বা `root` দিয়ে সরাসরি লগইন), আনঅথরাইজড স্কিমা পরিবর্তন এবং ডেটা এক্সফিল্ট্রেশন ট্র্যাকিং করার সেরা উপায় কী?
14. ডেটাবেজের "Slow Query Log" এবং ফেইল্ড অথেনটিকেশন লগ কীভাবে সংগ্রহ করবে যা ডেটাবেজ ব্রুট-ফোর্স বা ডিনায়াল-অব-সার্ভিস (DoS) শনাক্ত করতে কাজে লাগে?
15. ডেটাবেজের অডিট লগিং চালু করার পর প্রোডাকশন ডেটাবেজ ইঞ্জিনে CPU ও Disk I/O ওভারহেড সাধারণত কত শতাংশ বাড়তে পারে এবং তা কীভাবে নিয়ন্ত্রণ করবে?

### Topic 04: REST APIs & Cloud / SaaS Telemetry Integration

16. SaaS প্ল্যাটফর্ম (যেমন: Microsoft 365, Google Workspace, GitHub, Salesforce) থেকে লগ সংগ্রহের জন্য API পোলিং (Polling via Cron / Script) বনাম ওয়েবহুক (Webhook / Push-based)-এর মধ্যে কোনটি বেশি কার্যকর এবং কেন?
17. ক্লাউড API-এর মাধ্যমে লগ টানার সময় OAuth 2.0 টোকেন ম্যানেজমেন্ট, সিক্রেট রোটেশন এবং রেট-লিমিটিং (`HTTP 429 Too Many Requests`) কীভাবে হ্যান্ডেল করবে যাতে কোনো লগ মিস না হয়?
18. API পোলিং স্ক্রিপ্টে স্টেট ট্র্যাকিং (State / Bookmark / Cursor Management): সার্ভার বন্ধ হয়ে গেলে রিস্টার্টের পর স্ক্রিপ্ট কীভাবে মনে রাখে শেষ কোন টাইমস্ট্যাম্প বা ইভেন্ট আইডি পর্যন্ত লগ রিড করেছিল?
19. ওয়েবহুক রিসিভারের জন্য একটি নিরাপদ পাবলিক এন্ডপয়েন্ট ডিজাইন করার সময় HMAC Signature ভ্যালিডেশন এবং সোর্স আইপি হোয়াইটলিস্টিং কীভাবে করবে?
20. ক্লাউড অডিট লগ (যেমন: AWS CloudTrail, Azure Activity Log, GCP Cloud Audit)-এর বিশাল JSON ইভেন্টগুলো অবজেক্ট স্টোরেজ (S3 / Blob) থেকে সরাসরি ইভেন্ট-ড্রিভেন পাইপলাইনে (SQS / Event Grid) ইনজেস্ট করার মেকানিজম কী?

### Topic 05: Microservices, Containers & Distributed Tracing

21. মাইক্রোসার্ভিস আর্কিটেকচারে যখন একটি একক ইউজার রিকোয়েস্ট ১০টি ভিন্ন সার্ভিসের মধ্য দিয়ে যায়, তখন লগগুলোকে একত্রিত করতে Distributed Tracing Identifier (Correlation ID / Trace ID / Span ID) কীভাবে SIEM লগে ইনজেস্ট ও লিংক করবে?
22. ডকার কন্টেইনারাইজড অ্যাপ্লিকেশনের লগ হোস্টের ফাইলসিস্টেমে জমা না করে Fluentbit বা Vector দিয়ে সরাসরি মেমোরি থেকে শিপ করার আর্কিটেকচার কীভাবে কনফিগার করবে?
23. কুবারনেটিস ক্লাস্টারে "DaemonSet" ব্যবহার করে প্রতিটি নোড থেকে নোডের সমস্ত পডের লগ স্বয়ংক্রিয়ভাবে সংগ্রহ করার বেস্ট প্র্যাকটিস কী?
24. কন্টেইনার ক্র্যাশ করলে (CrashLoopBackOff বা OOMKilled) কন্টেইনার ডিলিট হওয়ার আগেই তার টার্মিনেশন লগ ও লাস্ট স্টেট কীভাবে SIEM এজেন্টে ক্যাপচার হবে?
25. মাল্টি-টেন্যান্ট মাইক্রোসার্ভিসে বিভিন্ন টিমের বা অ্যাপ্লিকেশনের লগের জন্য ক্লাউড নেমস্পেস বা ট্যাগ-বেসড ইনডেক্সিং কীভাবে পৃথক রাখবে?

### Topic 06: Multiline Parsing & Exception Handling

26. জাভা অ্যাপ্লিকেশনের এরর স্ট্যাক ট্রেস (Java Exception Stack Trace) বা পাইথন ট্রেসব্যাক সাধারণত ১০ থেকে ১০০ লাইনের হতে পারে—SIEM এজেন্ট কীভাবে বুঝবে মাল্টিলাইন লগের শুরু ও শেষ কোথায়?
27. মাল্টিলাইন পার্সিংয়ের জন্য `multiline.pattern`, `multiline.negate: true`, এবং `multiline.match: after` কনফিগারেশনের অন্তর্নিহিত মেকানিক্স উদাহরণসহ ব্যাখ্যা কর।
28. মাল্টিলাইন লগের বাফার সাইজ (`max_lines` বা `max_bytes`) সঠিক না হলে অসম্পূর্ণ বা ট্রাঙ্কেট হওয়া লগ কীভাবে পাইপলাইনে সমস্যা তৈরি করে?
29. ডেভেলপাররা যদি লগের মাঝখানে ইচ্ছাকৃতভাবে নিউ-লাইন ক্যারেক্টার (`\n`) ইনজেক্ট করে লগ স্প্লিট করতে চায় (Log Injection Attack), তবে পার্সার লেভেলে তা কীভাবে প্রতিরোধ করবে?
30. বিভিন্ন অ্যাপ্লিকেশনের মাল্টিলাইন ফরম্যাট ভিন্ন হলে (যেমন: XML পে-লোড বনাম জাভা এক্সেপশন) একই ফাইলে দুই ধরনের মাল্টিলাইন পার্সিং কীভাবে হ্যান্ডেল করবে?

### Topic 07: Data Privacy, PII Masking & Sensitive Data Scrubbing

31. GDPR, PCI-DSS বা HIPAA কমপ্লায়েন্স নিশ্চিত করতে লগ থেকে সংবেদনশীল তথ্য (ক্রেডিট কার্ড নম্বর, পাসওয়ার্ড, CVV, সোশ্যাল সিকিউরিটি নম্বর, ন্যাশনাল আইডি) কীভাবে পাইপলাইন লেভেলে মাস্কিং বা হ্যাশিং করবে?
32. ডেভেলপাররা অসাবধানতাবশত অ্যাপ লগে প্লেইনটেক্সট পাসওয়ার্ড বা এপিআই টোকেন প্রিন্ট করে ফেললে লগটি ইনডেক্সারে স্টোর হওয়ার পূর্বেই কালেক্টর বা প্রি-প্রসেসরে কীভাবে রেজেক্স দিয়ে স্ক্রাব (Scrub / Redact) করবে?
33. রিভার্সিবল এনক্রিপশন বনাম ওয়ান-ওয়ে ক্রিপ্টোগ্রাফিক হ্যাশিং (যেমন: SHA-256 with Salt)-এর মধ্যে পার্থক্য কী এবং কখন ইউজার আইডেন্টিফায়ার মাস্ক করার জন্য সল্টেড হ্যাশ ব্যবহার করা উচিত?
34. ডেটা মাস্কিংয়ের কারণে ডিটেকশন রুল বা সিকিউরিটি ইনভেস্টিগেশন যাতে বাধাগ্রস্ত না হয়, সেজন্য কোন তথ্যগুলো মাস্ক করবে এবং কোনগুলো ওপেন রাখবে তার ব্যালান্স কীভাবে করবে?
35. মাস্কিং পাইপলাইনে হঠাৎ কোনো নন-কমপ্লায়েন্ট পিআইআই (PII) ডেটা ইনজেস্ট হয়ে ইনডেক্স হয়ে গেলে প্রোডাকশন ইনডেক্স থেকে লিগ্যাল কমপ্লায়েন্স অনুযায়ী সেই নির্দিষ্ট ডকুমেন্ট কীভাবে পার্মানেন্টলি ডিলিট করবে?

### Topic 08: Ingestion Buffering, Backpressure & Pipeline Resiliency

36. একটি ফ্ল্যাশ-সেল (Flash Sale) বা হাই-ট্রাফিকের সময় অ্যাপ্লিকেশন লগ ভলিউম এক ধাক্কায় ১০ গুণ বেড়ে গেলে অ্যাপ্লিকেশনের যাতে কোনো ডেটা লস না হয়, সেজন্য ইন-মেমোরি বাফার ও ডিস্ক পারসিস্টেন্ট কিউ কীভাবে কনফিগার করবে?
37. লগ পাইপলাইনে যখন ব্যাকপ্রেশার (Backpressure) তৈরি হয়, তখন এজেন্ট বা শিপার অ্যাপ্লিকেশনের থ্রেডকে ব্লক করে দেয় কিনা এবং এটি প্রিভেন্ট করার জন্য নন-ব্লকিং কিউ কীভাবে কনফিগার করতে হয়?
38. Kafka বা RabbitMQ-কে অ্যাপ্লিকেশন ও SIEM-এর মাঝখানে মেসেজ ব্রোকার হিসেবে ব্যবহার করলে পাইপলাইনের ডিকপলিং ও ফল্ট টলারেন্স কীভাবে বহুগুণ বৃদ্ধি পায়?
